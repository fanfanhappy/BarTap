# BarTap 隐私与安全

## 本机数据

BarTap 当前在 `%APPDATA%\BarTap` 保存：

- 主题、外观、页面开关和功能设置。
- 待办、本机日程及提醒设置。
- 剪贴板历史与固定条目。
- 置物架保存的文件路径。
- 日历、AI 额度账号的连接元数据。
- 设置页自定义背景的图片路径；图片本身仍保存在原位置，不会复制到数据目录。

`BARTAP_DATA_DIR` 环境变量可以把数据目录临时改到其他位置。置物架只保存原文件路径，不复制文件正文；本机日程不会上传到工作日历。

## 凭据

日历密码通过 Windows 凭据管理器保存；独立 Gemini、WorkBuddy 会话使用当前 Windows 用户的 DPAPI 加密。连接元数据可能包含邮箱地址、账号名称和本机登录文件路径，因此整个数据目录都不适合公开上传。

## 日历

日历连接使用服务商提供的 CalDAV、Exchange ActiveSync 或兼容接口。BarTap 不修改工作日历，也不把本机日程上传到服务端。

## 网络访问

启用对应功能后，程序会联系：

- 工作日历 CalDAV / Exchange ActiveSync 服务。
- AI 服务额度接口。
- 歌词服务。
- GitHub 公开发布接口，用于检查更新。

请求内容和服务器见源码中的 `calendar.rs`、`quota.rs`、`lyrics.rs`、`updates.rs` 及对应 provider 模块。程序不会发送本地设置、日程正文或完整剪贴板历史。

音乐兼容功能会只读访问部分播放器的本机歌词缓存、播放日志和播放队列，只保留歌词、歌曲 ID、歌名、歌手、专辑、公开封面地址、播放状态和时间轴。不会修改播放器、读取音频或提取登录信息。

启动或运行异常的诊断日志保存在数据目录的 `diagnostics/`，不会自动上传。

## 通知

微信提醒根据任务栏闪动工作，不读取联系人或聊天正文。QQ 与 Windows 通知需要系统通知权限；通知正文默认隐藏，开启预览后按原样显示。

## 更新

点击「检查更新」时，程序访问 GitHub 的公开发布接口，并在请求头中包含 BarTap 版本号，不发送本地设置或日程数据。下载更新时，安装包保存到本机更新目录，核对大小与 SHA-256 后替换程序并重启。

## 边界

BarTap 不使用统一的云端账号，也没有项目自建的日程或账号上传后台。第三方服务自身的数据处理政策仍然适用。

不要把 Cookie、授权码、登录 JSON、凭据文件或私人日程提交到 GitHub Issue。
