# BarTap 使用指南

> BarTap 使用 `bartap` 作为可执行文件，用户数据保存在 `%APPDATA%\BarTap`。

## 第一次打开

第一次启动会先出现三步引导：外观模式、灵动岛形态、常用功能。选完点「开始使用」；不想设置可以直接「跳过」，之后仍可在设置里调整。老版本升级不会再次弹出引导，可以在 **设置 → 关于 → 重新查看引导** 打开。

鼠标靠近屏幕顶部的岛会展开功能面板。左右箭头、底部圆点和鼠标滚轮都可以切换页面；列表内部滚轮优先滚动列表。

托盘菜单可以打开设置、切换开机启动、查看关于信息或退出程序。

如果看不到岛，先检查：

- 托盘是否已经有 BarTap 在运行。
- 设置 → 常规 → **全屏时隐藏** 是否开启。开启时，前台最大化窗口会让岛自动隐藏。
- 岛是否停靠在其他显示器，或当前显示器缩放/多屏组合导致位置偏移。

设置里的功能页面开关只隐藏页面，不删除数据。

## 主题与外观

**设置 → 常规 → 外观主题**

| 选项 | 行为 |
| --- | --- |
| 跟随系统 | 跟随 Windows 应用主题，系统切换后实时更新 |
| 浅色 | 始终使用 Fluent Light Token |
| 深色 | 始终使用 Fluent Dark Token |

**设置 → 常规 → 岛体外观**

| 选项 | 行为 |
| --- | --- |
| 纯色 | 使用当前主题的主背景色，资源占用最低 |
| 毛玻璃 | 使用 Windows 实时模糊，主题色半透明叠加 |
| 悬浮云 | 背景随音乐封面换色，控件仍使用 Fluent 主题 |

**设置 → 常规 → 设置页背景**

- 选择本地 PNG、JPEG 或 WebP 图片作为设置窗口背景。
- 图片自动铺满窗口并居中裁切，不会拉伸变形。
- 调整「遮罩」百分比控制主题色覆盖程度；遮罩越深，文字越清晰。
- 「清除」恢复当前主题的纯色设置背景；该图片只影响设置窗口，不影响悬浮岛。

主题、卡片、按钮、输入框、菜单和弹窗共用一套 Token。

**调整岛体大小**

- 展开岛后，右下角会出现缩放手柄。
- 按住手柄拖动，松开后保存新尺寸；拖动时会显示当前百分比，窗口倍率会平滑追上指针，不会逐级跳变。
- 双击手柄恢复 100%。

设置页不再提供大小滑块，避免和直接拖动重复。

## 性能

性能页通过岛内第 3 页查看，不打开独立窗口。

| 卡片 | 内容 |
| --- | --- |
| CPU | 总占用、逻辑线程数、60 秒趋势 |
| 内存 | 已用 / 总量、百分比、60 秒趋势 |
| 网络 | 当前下行 / 上行速率 |
| 存储 | 系统盘剩余空间与占用比例 |

每秒刷新一次；离开性能页后暂停采样。可在 **设置 → 页面管理** 中关闭或调整顺序。性能页只读取本机数据，不读取进程名，不上传任何信息。

## 音乐与歌词

音乐信息来自 Windows 媒体会话。播放器需要向系统提供标题、歌手、时长和播放状态。

- 点击岛上的播放/暂停、上一首/下一首、音量或进度条进行控制。
- 展开歌词后，右侧显示同步歌词；收起时可以只保留岛上单行歌词。
- 歌词匹配依赖歌曲元数据和歌词服务，个别版本、纯音乐或未找到歌词的歌曲可能无法显示同步歌词。

## 专注

专注与休息使用独立计时。点击开始后，收起岛仍能看到进度环；阶段结束后会提醒进入下一阶段。

计时时长可以在 **设置 → 专注** 中调整，下一阶段生效。

## 待办

待办支持：

- 单次提醒：通过日期/时间选择器设置。
- 每周指定日期重复。
- 每天重复。
- 完成后自动恢复下一次重复。

到点后岛会弹出提醒；点击提醒可以回到待办页。已完成和未完成状态按当天计算。

## 日历

在 **设置 → 通知与日程 → 日程** 中添加日历。支持：

- 飞书、钉钉、企业微信、iCloud。
- 自定义 CalDAV。
- 兼容的 Exchange ActiveSync。
- `.ics` 文件导入。

日历页左侧是月历，右侧是当天时间线。跨天日程会出现在覆盖的日期中；会议提醒可提前 5 / 15 / 30 分钟。

只安装或登录桌面客户端不会自动授予日历读取权限。程序退出、关机或睡眠期间无法持续提醒。

## AI 额度

在 **设置 → AI 额度** 中连接账号。支持 Codex、Claude、Kimi、Grok Bot、Gemini、ZCode、WorkBuddy 和 DeepSeek。

- 多个账号可以分别命名、选择配色，并决定是否常驻岛上。
- Codex、Claude、Kimi 等本机登录由原工具管理，BarTap 只读使用，不修改原客户端配置。
- 额度接口、订阅类型和服务商策略可能变化；未识别或请求失败时，以对应服务商官方页面为准。

## 置物架与剪贴板

**置物架**：把文件拖入岛内临时收集，点击打开、定位原文件，或拖出到其他应用。移除记录不会删除原文件。

**剪贴板**：保存最近复制的文字，点一下重新复制，常用内容可以固定。历史保存在本机；关闭记录会暂停收集，密码管理器标记为敏感的内容不会记录。

## 通知与系统状态

- 微信、QQ 与 Windows 通知：收起时显示图标和红点，展开后可查看并切换窗口。
- 音量、电量、充电、网络、蓝牙设备和输入语言：以轻量 HUD 显示。
- 通知正文默认隐藏；可在设置中开启预览。

## 更新、卸载与数据目录

用户数据保存在 `%APPDATA%\BarTap`。

- 更新包发布后，可在 **设置 → 关于 → 检查更新** 中检查并安装。
- 卸载程序会移除程序和快捷方式，但保留用户数据。
- 如需彻底清除账号，先在设置中移除对应连接，避免只删配置文件而留下系统凭据。

## 常见问题

**岛没有出现：** 检查托盘、全屏隐藏设置、当前显示器和最大化窗口。

**日历连接成功但没有日程：** 手动同步所选月份，确认授权日历包含该日程；不要提供密码。

**界面颜色异常：** 反馈 Windows 版本、主题模式、背景材质、屏幕缩放和截图；截图先遮挡账号和私人日程。
